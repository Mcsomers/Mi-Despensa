
## Compilación automática en GitHub
Este repositorio incluye el flujo `.github/workflows/android.yml`. Al subir cambios a `main` o `master`, GitHub Actions compila la APK. También puedes iniciarlo manualmente desde **Actions > Compilar Mi Despensa Pro > Run workflow**. Cuando termine, abre la ejecución y descarga el artefacto **Mi-Despensa-Pro-APK**.
