# Mi Despensa Pro

Aplicación Android inicial para administrar productos de la despensa y un presupuesto semanal de viernes a viernes.

## Funciones incluidas en esta primera versión
- Agregar productos con cantidad en piezas, gramos o kilos.
- Registrar un valor estimado por producto.
- Calcular el total registrado y el presupuesto disponible.
- Cambiar el presupuesto semanal.
- Guardar los datos localmente en el teléfono mediante preferencias privadas; no requiere internet para el uso diario.

## Abrir y compilar
1. Descarga y descomprime este proyecto.
2. Abre la carpeta `DespensaPro` desde Android Studio.
3. Espera la sincronización de Gradle (la primera compilación necesita internet para descargar herramientas y dependencias).
4. Ejecuta la app en un teléfono o genera el APK desde **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
